# Credit Card Fraud Detection System

## Overview
This project is a Machine Learning based Credit Card Fraud Detection System that detects fraudulent transactions using classification algorithms.

The model is trained on transaction data and predicts whether a transaction is genuine or fraudulent.

---

## Features
- Data preprocessing
- Handling imbalanced dataset
- Machine Learning model training
- Fraud prediction system
- Flask web application
- User input prediction

---
